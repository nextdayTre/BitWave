# Decision log

Implementation decisions taken to keep the plan moving. Each one is reversible
while the codebase is small; the ones the plan marked for the author are noted.
Format is deliberately short: decision, basis, how to reverse it.

**Status:** 2026-11-06 · applies to the `src/core` extraction, the F0 baseline, the browser-verification harness, the `window.BitWave` seam, the Vite build (D19), the F2 state/render/UI spine (D20–D23), the F3 source table (D24–D25), the F4 accessibility floor + IA pass (D26–D32), F5 persistence & reach (D33–D36), F6 distribution (D37–D38), the dynamic-lanes pass (D43–D46), the GUI rearrangement (D47) and the dataset readback (D48).
