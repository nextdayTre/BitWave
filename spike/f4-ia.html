annotations — dashed outlines + numbered circles are review markup, not UI

One line per change. Adaptations from the shipped shell are flagged in the note at the foot.

1

width, not register

Header slider label only. Layout, range, and the 64 bits · 16 nibbles readout are unchanged; the thumb is now a 24 px target.

2

Stage bar in both views

Always visible. Lane 1 2 3, frames, split, pane focus and the routing-aware expression (LANE 1 · A ⊕ B → Z1; a route would show the column, e.g. sine ⊕ B → Z1) live only here. In 2-D split stays put, aria-disabled; in split 3-D each pane gets its own focus dot (specimen below).

3

Frame navigator = focus lens (D16)

Three lanes; each lane's frames use one global name set — A/Z1/B, C/Z2/D, E/Z3/F. Derived frames focus read-only; unpair B sits in this footer. Still a transient aside, not an inline mode. At 360 px it would cover the whole stage, so that shot shows it closed.

4

One spinbutton per nibble

Each nibble is a focusable role="spinbutton" (0–15, arrows/Home/End/0–F, roving tabindex); the whole cell is the pointer target and the accent ring marks keyboard focus. At 720 px the strip is compact (pw/n < 46) and drops to hex-only, but the spinbutton survives. Stage-bar .op.mini targets are raised to a 24 px minimum too.

5

Whole-word hex entry

A mono field beside the edit target: type DEADBEEF and press Enter; left-padded (and high-bit truncated) into the register width. Closes the per-bit keyboard dead end.

6

source is first and fixed

import csv / ◀ 3/120 ▶ / sources / log / export, then one status line immediately below the module. Nothing appears or disappears: before a load the stepper and log/export render aria-disabled in place (specimen). sources still opens the six-row transient aside (D25).

7

operate moves before derive

amount + the seven unary ops, with the eight shape presets folded in under a presets sub-label so they remain one module. (Was the last group, bit ops, plus a separate shape group.)

8

derive is a real radiogroup

Operand B is stated, not toggled: B is enabled by focusing a B/D/F frame or entering 3-D, and removed with unpair B. AND OR XOR ADD SUB are role="radio" with aria-checked; with no B they stay visible, aria-disabled, and truth/carry shows an empty state.

9

motion keeps its slot

LFO, mode, rate and B phase are the same controls, but they no longer move around when B appears. Stable fifth module, after derive.

10

view = 2-D/3-D + copy to…

The duplicated lane select and split are removed from this row — the stage bar is their single canonical home. Nothing here changes the view's state silently.

11

copy to… is explicit

A 1 / 2 / 3 menu opens under the button; focus moves into it, Escape cancels and returns focus, and the status line (6) reports copied lane 1 → lane 2. No invisible armed mode, no silent rename. (Drawn expanded in flow here for legibility; it overlays in the app.)

12

Truth/carry belongs to derive

It stays in the meta band beside the values it explains; counts 23 11 9 21 sum to 64. The n column keeps its separating rule — it is data about the register, not a fifth logic cell.

Adapted to the shipped shell, not the older audit tables: there is no A|B edit-target segmented pair and no toggleB button in src/index.html today. The edit target is the frame navigator's focus lens (D16) and is shown as the read-only edit · A statement; B is enabled by focusing a B/D/F frame or entering 3-D and removed by unpair B. The demo button is F5 scope and is deliberately absent. Lanes are 1 / 2 / 3; letters belong only to frames and operands.

Not changed: two hues only — accent green is data, --inf amber stays structural (MRB, zero-crossing, ∞); mono for values, sans for labels; no onboarding, trophy or cable graphics; Z1/Z2/Z3 never editable and the 3-D field never editable; MSB-left hardware bit order; --pad as the single gutter authority and the 0 px strip↔curve column alignment.
